# App Icons for COAI PWA

Place your app icons in this directory with the following specifications:

## Required Icons

### Main App Icons
- **icon-192x192.png** - 192x192 pixels (required for PWA)
- **icon-512x512.png** - 512x512 pixels (required for PWA)

### Shortcut Icons (Optional)
- **chat-192x192.png** - 192x192 pixels (for "New Chat" shortcut)
- **synth-192x192.png** - 192x192 pixels (for "Create Synth" shortcut)

## Icon Requirements

1. **Format**: PNG format
2. **Background**: Should work on any background (consider using a solid background or transparent with fallback)
3. **Design**: Simple, recognizable, and works at small sizes
4. **Maskable**: Icons should work with the "maskable" purpose (safe area in center)

## Recommended Sizes for Complete PWA Support

For the best PWA experience, consider adding these additional sizes:
- 72x72, 96x96, 128x128, 144x144, 152x152, 384x384

## Design Guidelines

- Keep important elements in the center 80% of the icon (maskable safe zone)
- Use high contrast for visibility
- Avoid fine details that won't be visible at small sizes
- Consider the app's branding and color scheme
